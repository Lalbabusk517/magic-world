## ✨ Features
* 🔐 **User Authentication:** Sign up and Log in using Email or Social Accounts.
* 📝 **Community Feed:** Share your thoughts, photos, and videos (up to 20MB).
* ❤️ **Interactions:** Like, comment on posts, and report inappropriate content.
* 🛡️ **Community Guidelines:** Safe space with privacy and content security practices.
* 📱 **Mobile Friendly:** Clean and dark-themed responsive user interface.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, Modern JavaScript (ES Modules)
* **Backend / Database:** Supabase (Auth, Database, Storage)
